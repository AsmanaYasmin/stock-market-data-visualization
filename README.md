# Multi-Asset Stock Market Data Analysis & Visualization

A comprehensive data analytics project exploring historical equity trends, daily return distributions, risk-volatility correlation, and portfolio asset allocation.

##  Features
- **Trend Analysis:** Visualizing historical stock performance across major technology companies (Facebook, Twitter, Netflix) from 2013 to 2020.
- **Risk & Volatility Assessment:** Statistical parametric analysis analyzing daily returns, displaying standard deviation ($\sigma$) and distribution means ($\mu$) via histograms.
- **Correlation Mapping:** Scatter plots evaluating cross-asset return dependencies.
- **Portfolio Allocation:** Custom exploded pie charts illustrating proportional capital allocation across multiple holdings.

##  Tech Stack
- **Languages:** Python
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
- **Tools:** Jupyter Notebook
